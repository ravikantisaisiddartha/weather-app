# 🌦️ India Weather App

## 📌 Project Description
India Weather is a Flutter-based mobile application that displays weather information for different states and union territories of India. Users can select a state or search for an Indian city to view weather details through a simple and attractive user interface.

**Note:** This project currently uses sample weather data for demonstration purposes. It does not display live weather information.

## ✨ Features
- 🌤️ Attractive weather dashboard
- 🇮🇳 Supports Indian states and union territories
- 🔍 Search for cities and states
- 🌡️ Displays temperature and feels-like temperature
- 💧 Shows humidity
- 💨 Displays wind speed
- ☁️ Shows weather conditions
- 📅 Five-day sample weather forecast
- 🔄 Refresh weather display
- 📱 Responsive Flutter UI
- 🎨 Dark blue gradient theme

## 🛠️ Technologies Used
- **Frontend:** Flutter
- **Programming Language:** Dart
- **UI Framework:** Material Design
- **IDE:** Visual Studio Code / Android Studio

## 🚀 How to Run the Project

### Prerequisites
- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android emulator or a physical device

### Installation Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/india-weather-app.git
   ```

2. Open the project folder:

   ```bash
   cd india-weather-app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## 📱 Application Modules

### 1. State Selection
Users can select an Indian state or union territory from a dropdown menu.

### 2. City Search
Users can search for a city or state by entering its name.

### 3. Current Weather
Displays the selected location, temperature, weather condition, and feels-like temperature.

### 4. Weather Details
Displays humidity, wind speed, feels-like temperature, and precipitation.

### 5. Five-Day Forecast
Displays a sample five-day forecast with weather conditions and temperatures.

## ⚠️ Limitations

- Live weather data is not integrated.
